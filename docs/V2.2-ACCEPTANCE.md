## 同条件软件渲染对照

1440×1000 视口、DPR 0.65；各场景预热 60 帧后采样 60 帧，顺序运行，未与其他 GPU 测试并行。

| 版本 / 画质 / 场景 | 平均帧耗时 ms | 中位 ms | P95 ms |
| --- | ---: | ---: | ---: |
| 上一稳定版本 / 原画质 / 全景 | 182.65 | 169.30 | 236.70 |
| 上一稳定版本 / 原画质 / 已对齐（无动态近景） | 181.75 | 167.00 | 235.50 |
| V2.2 / 高 / 全景 | 203.90 | 186.20 | 274.50 |
| V2.2 / 高 / 连接近景 | 217.15 | 194.50 | 301.40 |
| V2.2 / 自动回退 / 全景 | 128.27 | 116.50 | 205.20 |
| V2.2 / 自动回退 / 连接近景 | 137.29 | 122.30 | 224.10 |

高画质全景相对稳定版平均帧耗时增加约 12%；近景包含更大的场景投影面积，增加约 19%。真实 GPU 帧率仍未验收，不能将此标为性能通过。自动画质已实际回退（`balanced: true`）：关闭 Bloom、雪从 2100 降到 1400、反射改为每 8 帧刷新。这是牺牲部分效果后的真实结果，不是同画质加速或普通设备流畅性证明。

复现示例：`CHROMIUM_PATH=/usr/bin/chromium BENCHMARK_DPR=.65 BENCHMARK_QUALITY=high node scripts/benchmark-cinematics.mjs http://127.0.0.1:4175/xndf-great/`。把 quality 改为 `auto` 可检查实际质量回退。
