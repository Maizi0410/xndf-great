## 五次过渡与组合

一个场景，三组机构，五次跨越。角色停在固定安全石台上；按所在安全节点自动选择可操作机构，上一机构的方向会保留。中央轴通过联动机构改变多段桥的方向，西阶与高处回廊各保留自己的折叠方向。每段构件的世界支点、端点、控制变量与深度差统一定义在 `src/game/puzzle.ts`。

| 安全位置 | 当前机构 | 主要有效组合 | 获得的道路 |
| --- | --- | --- | --- |
| A 起点 | 中央轴 | 轴 −56° | A → 西侧悬阶 L |
| L 西阶 | 折叠阶 | 轴 −56°，阶 +34° | L → 中庭 B |
| B 中庭 | 中央轴 | 轴 +52°，阶保持 +34° | B → 东侧回廊 U；此前的来路失效 |
| U 回廊 | 高处回廊 | 轴 +52°，廊 −38° | U → 中央上庭 B2 |
| B2 上庭 | 中央轴 | 轴 −22°，阶 +34°，廊 −38° | B2 → 终点 C；再次取消已用连接 |

这张表是课堂展示者的解答，游戏界面不会直接显示目标角度。「观察提示」只指出应观察的端点与方向。目标初见约 5–8 分钟、熟悉后约 2–4 分钟，尚未进行真人计时验证。

两种误导状态：西阶 −34° 时端点位置重合但末段折返、方向不连续；中庭轴 +18° 时远处桥端重合，但桥的起点不在人物当前可达的安全石台上。反复点击/捏合不会放行。任意安全节点都能从任意当前角度再次旋转到解，行走锁定所有机构，没有需要重开才能恢复的角度顺序陷阱。

## 投影、规则与连续行走

`assessConnection` 用实际正交摄影机矩阵，把世界端点投影为当前视口像素；容差由同一摄影机下一个世界单位的像素尺度得到。还检查两侧投影切线方向、实际建筑遮挡射线、完整机构组合、当前石台到桥入口的距离。不是按角度直接宣布道路存在。小范围松手磁吸为 ±4°，连续稳定窗口保留 0.45 秒。

`WorldRules` 是通行与冰面许可的唯一来源：失去许可立即禁止确认，旧冰先融化完，新冰才凝结；行走期间锁定机构。渲染与判定调用同一个 `bridgePose`，不各自猜测连接。所有角色路线均从石台沿桥段前往实际桥端，再沿固定摄影机的视线方向连续转移到另一个深度，随后沿下一段桥走向安全平台。正交投影保持尺度，摄影机在解谜期间不旋转；结束后才缓慢后拉。桥端世界距离约 1.6–2 米，并非真正相接的普通桥。

雪在接近当前可用路线时沿两侧阶边汇聚；杆灯、电线和冰晶提供许可反馈；失效后雪重新飘散。石材摩擦、缆线共鸣、凝结、融化和材质脚步由本机 Web Audio 合成。

## 输入、运行与验证

张开手掌左右移动、捏合确认保留。`gesture-math.ts`、识别阈值和本地模型不变；到达新安全节点时重新建立手掌角度基准。鼠标拖动场景或底部刻度，合法后点击「允许前行」；键盘左右和 Enter 也可操作。摄像头失败可完整使用鼠标。

网页：https://guoanze550-commits.github.io/xndf-great/ 。部署真实结果由 Actions 的 `Deploy web game to GitHub Pages` 及 `web-deploy-status` 分支 `latest.json` 记录。发布后须同时核对 `build-info.json` 的 `source_commit`，避免把旧网页当成新版。提交本身不等于部署成功。

本地版保留 `npm run classroom:mac` 和原有 Mac 工作流；版本为 0.2.0。Actions → Build classroom Mac ZIP → 对应 V2 提交 → Artifacts 下载 `The-Permitted-World-Classroom-Mac-Apple-Silicon-arm64`。解开外层 Artifact，再解开内层课堂 ZIP，运行 `.app`。本地资源、WASM 与 MediaPipe 模型均随包分发，无需联网。V1 的 0.1.0 Artifact 属于旧版，不能当成 V2 验证。

自动检查包括类型检查、真实投影/遮挡/多分辨率与组合规则测试、五段鼠标完整通关、拒绝摄像头后的通关、Pages 子路径和本地推理、Electron 阻断外网后的五段通关。每轮实际结果单独记录在 `docs/V2-ACCEPTANCE.md`。

仍需人工验收：真实手部输入、Safari/Windows 实机、视觉错觉跨缝时的遮挡观感、初见解谜时间、课堂 Mac 安全提示及硬件帧率。合成摄像头和 Linux 软件渲染不能证明这些项目已通过。
