# 《界限》课堂使用说明

**THE PERMITTED WORLD · 课堂主题作业**

作品主题：**秩序通过划定边界与限制可能性而形成控制。** 你允许一条路出现，另一条路就必须消失。人物得以前行，也因此失去其他方向。

## 两种体验方式

- **网页版（Mac / Windows）**：https://guoanze550-commits.github.io/xndf-great/ 。需要网络和已成功部署的 GitHub Pages。当前云端无法检查公网部署状态，课前请用课堂网络实际打开确认。
- **本地断网版（Apple Silicon Mac）**：解压课堂 ZIP，打开其中的 `The Permitted World.app`。可先复制到「应用程序」或本机文件夹；运行时不需要安装 Node.js、不需要服务器，也不需要联网。

系统要求：网页使用支持 WebGL 2、WebAssembly 的现代 Safari、Chrome 或 Edge，建议开启硬件加速；本地版需要 **M1 或更新芯片、macOS 13 或更高版本**。Windows 使用网页版，本次不提供 Windows 本地应用。

## 鼠标玩法（课堂首选）

1. 点击「进入界限」。
2. 按住场景左右拖动，或拖动底部刻度至 **−60°** 附近；等待 I—II 冰路完整凝结，点击「允许前行」。
3. 人物到 II 后，将刻度转至 **+60°** 附近。旧路先融化，新路再出现；再次确认，人物沿 II—III 抵达门。
4. 行走中暂时不能旋转；完成后可重新开始。右上角可关闭声音。

## 两个手势（增强体验）

点击「启用手势」并允许摄像头，将一只手完整放进预览画面：

- **张开手掌，左右移动**：保持片刻校准，然后控制旋转。
- **拇指与食指捏合**：道路有效时确认前行；松开后才可再次确认。

找不到手时输入暂停，可重新校准。「−」只隐藏预览，「关闭摄像头」才会停止摄像头。视频只在本机处理，不上传、不录制。网页版手势需要 HTTPS 和浏览器/系统摄像头授权；摄像头失败或没有设备时，**始终可以使用鼠标完成全部流程**。

## 获取本地课堂 ZIP（教师 / 展示者）

相关 `main` 提交会自动构建。打开仓库 Actions → **Build classroom Mac ZIP**，选择最近成功的运行；也可用 **Run workflow → main** 手动构建。成功后下载 Artifact：

`The-Permitted-World-Classroom-Mac-Apple-Silicon-arm64`

先解开 GitHub 的外层 Artifact ZIP，再解开里面的：

`The-Permitted-World-0.1.0-classroom-macOS-Apple-Silicon-arm64.zip`

其中包含 `.app`、本说明、资源许可及验证信息。工作流不需要 Apple 开发者账户或任何签名密钥，只使用本机 ad-hoc 签名；未做 Developer ID 签名或公证，系统仍可能出现安全提示。仅对可信课堂包按「系统设置 → 隐私与安全性」提供的步骤处理，不关闭系统整体安全保护；**课前务必在演示 Mac 上实际启动并断网通关一次**。

如果文件名带 `UNVERIFIED-crossbuild`，它仅是 Linux 生成的未验证备份，不要当作已经通过 Mac 启动测试的课堂包。

## 三分钟课堂展示

1. **课前**：打开网页，或将 `.app` 放到演示 Mac；检查画面、鼠标和投影，离线展示时先关闭网络并试通关。
2. **开场**：用一句话介绍「一条路得到许可，另一条路就失去可能」。
3. **演示**：鼠标完成 I→II，再切换到 II→III；让同学观察旧路消失的过程。
4. **可选**：重新开始，演示张开手掌和捏合。识别不稳时立即换回鼠标，不影响展示。
5. **收尾**：展示结局文字，讨论「谁决定了可以走的方向」。

验证边界：合成视频推理不代表真实摄像头测试；Linux 自动通关不代表 Mac / Windows 实机验收。当前真实结果见仓库 `docs/CLASSROOM-ACCEPTANCE.md`。
